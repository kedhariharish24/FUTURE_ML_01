# Power BI — Optional Visualization

After running `sales_forecasting.py`, open Power BI Desktop.

1. Select **Get Data → Text/CSV**.
2. Import:
   `outputs/monthly_sales.csv`
3. Create a **Line Chart**:
   - X-axis: Date
   - Y-axis: Monthly_Sales
4. Import:
   `outputs/future_30_day_forecast.csv`
5. Create another **Line Chart**:
   - X-axis: Date
   - Y-axis: Forecast_Sales
6. Add a title such as:
   **30-Day Sales Forecast**

You can also use the PNG charts generated by the Python program in your report/PPT.
